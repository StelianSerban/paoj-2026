# Catalog

## 1.1 - Actiuni posibile in sistem

1. Adauga un student
2. Adauga un profesor
3. Inregistreaza o nota pentru un student
4. Cauta student dupa nume
5. Afiseaza toate notele unui student
6. Calculeaza media unui student la o materie
7. Listeaza toti studentii dintr-o grupa
8. Afiseaza materiile predate de un profesor
9. Afiseaza studentul cu cea mai mare medie la o materie
10. Sterge un student din catalog
